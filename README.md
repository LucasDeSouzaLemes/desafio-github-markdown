# Projeto final

Entenda os conceitos fundamentais para versionar código e colaborar em projetos:

---

### Fundamentos

* **Git:** É a ferramenta que roda direto no seu computador. Ele funciona gravando (commits) de todo o histórico de alterações dos arquivos locais, sem depender de internet.
* **GitHub:** É o serviço em nuvem onde você hospeda seus projetos que usam Git. Ele serve como ponto de encontro da equipe, permitindo sincronizar versões, revisar código e automatizar rotinas.
