### Fundamentos

* **Git:** É a ferramenta que roda direto no seu computador. Ele funciona gravando (commits) de todo o histórico de alterações dos arquivos locais, sem depender de internet.
* **GitHub:** É o serviço em nuvem onde você hospeda seus projetos que usam Git. Ele serve como ponto de encontro da equipe, permitindo sincronizar versões, revisar código e automatizar rotinas.

---

### Fluxo de Trabalho e Código

* **Branches (Ramificações):** Linhas paralelas de desenvolvimento criadas a partir do código principal (`main`). Permite que você desenvolva uma funcionalidade nova ou corrija um erro em outra branch, sem correr o risco de quebrar o projeto que está funcionando.
* **Merges (Mesclagens):** Serve para unir duas branches. Quando você faz uma alteração de código e testa ela em uma branch separada, o merge integra essas alterações de volta à linha principal.

---

### Gestão e Documentação no GitHub

* **Issues:** Espaço dedicado para organizar o trabalho dentro do repositório. Funcionam como tickets para apontar bugs encontrados, registrar solicitações de novas funções ou distribuir tarefas para o time.
* **Gists:** Ferramenta do GitHub para compartilhar trechos rápidos de código, scripts avulsos ou anotações curtas via link, dispensando a criação de um repositório completo.
* **Wiki:** Sistema de páginas de documentação integrado ao repositório. Ideal para manuais de instalação aprofundados, diretrizes de arquitetura e guias de usuário que seriam extensos demais para ficar apenas no arquivo `README.md`.
